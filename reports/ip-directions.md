## 세 안의 차이

- [1안 · 기존 기본안](https://mini920325-gif.github.io/site-lab-artifacts/candidates/claude/?view=home): 지금까지 만든 홈과 기능을 기준으로 보존한다. 기존 URL과 브라우저 디자인·메모 저장 키를 유지한다.
- [2안 · 제도와 일상](https://mini920325-gif.github.io/site-lab-artifacts/candidates/ip-2/?view=home): 직접 정리한 글 → 공식 자료 → 질문 순서로 읽는 편집형 화면. 남색 선, 명조 제목, 넓은 본문 간격을 사용한다.
- [3안 · 일상동료](https://mini920325-gif.github.io/site-lab-artifacts/candidates/ip-3/?view=home): 분야별 대화 → 경험 목록 → 필요한 자료 순서의 게시판. 벽돌색, 간결한 도입, 촘촘한 목록을 사용한다.

‘제도와 일상’과 ‘일상동료’는 비교용 제안 이름이다. 최종 상호·상표·도메인은 결정하지 않았다. 상단에서 안을 이동하거나 세 기본 홈을 같은 폭으로 비교할 수 있다.

## 이번에 담은 정체성

공개 기획에 있는 행정사무소 목적과 전직·취업·창업·교육·생활·보훈의 연결을 출발점으로 삼았다. 그 분야를 읽고 질문하는 독자에게 쓸모 있는 편집 방식과 글을 직접 만들었다. 비공개 사건·상담 기록이나 실제 회원 글은 사용하지 않았다.

- ‘한 장으로 읽기’: 긴 공고문을 원문·시점·확인할 질문으로 나눠 읽는 방법.
- ‘경험의 언어’: 해온 일을 다음 일에 설명할 문장으로 정리하는 방법.
- ‘질문의 기술’: 막연한 질문을 한 장의 메모로 만드는 방법.

세 편 모두 편집 콘텐츠 예시다. 실제 상담 실적이나 회원 경험으로 표시하지 않는다. 공식 기관의 원문과 커뮤니티의 경험 글을 화면에서 구분하며, 기관 제휴나 전문가 자격·성과를 새로 주장하지 않는다. 특정 급여 자격이나 법률 결론을 제공하는 글은 이번 범위에 없다.

## 기존 기능과 저장

32개 출발 조합과 화면·색상·목록·글꼴·여백·모서리·기호의 독립 7축을 세 안 모두에서 유지한다. 2·3안은 색만 바꾼 프리셋이 아니라 홈의 구성과 읽기 순서가 다른 안이다. 세 안 비교는 기본 디자인으로, 각 안 안의 디자인 비교는 현재 조합과 변경 조합으로 동작한다.

위치 메모·다른 이름 저장·저장본 관리·JSON 복원·Markdown 수정 요청·시각 참고 HTML도 유지한다. 각 안의 설정과 메모는 별도 브라우저 키에 보관한다. 다른 안의 JSON을 잘못 가져오면 해당 안으로 이동하도록 안내하며, 같은 안에서 가져올 때는 기존 저장본을 덮지 않는 사본으로 연다. JSON·Markdown·HTML에는 안 번호·이름·경로가 포함된다. 에이전트에게 자동 전송하지 않는다.

현재 안을 다시 눌러도 작성 화면을 새로 불러오지 않는다. 다른 안으로 이동할 때 미등록 글·댓글이 있으면 확인한다. 작성한 체험 글·댓글은 기존처럼 메모리 시연이며 실제 인증·DB와 연결되지 않는다.

기존 A/B/C 정적 편집기와 Fable 후보도 보존한다. A/B/C 편집기의 메모는 별도 형식이며 자동 이전하지 않는다.
