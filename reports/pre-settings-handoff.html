현재 단계와 종료 조건

GitHub 문서로 읽기 · Markdown 원문

상태 기준: 2026-10-13. Claude 기능판에 위치 메모·다른 이름 저장·에이전트 전달을 연결했습니다. 로컬 검증을 완료했고 공개 반영·익명 접근을 확인할 차례입니다. 이전 디자인 조합 공개의 완료 기록과 이번 추가분의 완료를 구분합니다.

  • Fable 비교 후보: 원본 577ce8bf8f7822771dfd674ae69a61f68aaa36d6.
  • 기존 정적 편집기: 삭제하지 않았습니다. A/B/C와 메모·이름 저장을 계속 사용할 수 있습니다.
  • 통합 실행 플랜: 전체 로드맵과 현재 범위.

두 React 후보의 글·댓글·내 활동은 합성 예시와 메모리 시연이며 새로고침하면 초기화될 수 있습니다. 디자인·검토 메모·이름 저장본은 해당 브라우저에 보관합니다. 기존 정적 편집기와 새 기능판은 저장 키와 형식이 달라 자동 이전되지 않습니다. 실제 인증·DB·서버 권한은 연결하지 않았습니다.

이번에 연결하는 검토 흐름

A–AF 32개 출발 조합과 7개 독립 축을 유지하고, 같은 1280px 홈의 비교·취소·적용에 위치 메모와 이름 저장을 연결합니다. 메모는 노랑·분홍·파랑·초록 4색이며 편집·완료 표시·삭제할 수 있습니다. 작업 중 메모의 임시 저장과 저장본의 명시 저장을 구분하고, 다른 이름 저장은 원본을 보존합니다. JSON 가져오기는 기존 저장본을 덮지 않는 별도 사본으로 엽니다.

JSON은 설정·메모 복원용, Markdown은 에이전트 수정 요청용, 독립 HTML은 화면과 메모를 보여 주는 시각 참고용입니다. HTML을 실제 회원 서비스나 편집 가능한 기능판으로 취급하지 않습니다. 전달 파일에는 기준 소스·7개 축·페이지·위치·메모·완료 상태가 들어가며, 메모는 사용자 검토 데이터입니다. 내려받은 파일을 직접 전달하는 방식으로 에이전트에게 자동 전송하지 않습니다.

저장본은 최대 30개, 시안별 메모는 100개, 메모 내용은 2,000자, 시안 이름은 80자, 가져오는 JSON은 1MB 이하입니다. 저장 한도와 브라우저 저장 실패는 기존 저장본을 조용히 지우지 않고 안내합니다. 여러 탭의 저장 충돌도 알리며 현재 작업의 JSON을 별도로 보관할 수 있습니다.

E1 · 로그인 없는 입구와 원본 연결

상태: 이전 디자인 공개 확인 완료, 이번 추가분은 공개 전.
종료 조건: 새 메모 기능이 포함된 후보·전달 원본·현재 문서를 OpenAI 로그인 없이 열 수 있고 배포 버전과 출처가 일치합니다.
기존 근거: 디자인 조합 공개에서는 로그인·쿠키 없는 13개 파일 응답·해시와 브라우저 적용·복원을 확인했습니다. 기준 소스 aee3beadcf337be7d30e797eb3de8d7bf26079d3, Pages b2de8de50bb5049718e995ef4032670aa424d978의 결과이며 이번 메모 추가분을 검증한 결과는 아닙니다.
최종 결과: 로컬 검증 진행, 공개 전. 새 공개 URL·배포 버전·익명 확인 결과를 여기에 기록합니다.

E2 · 후보 경로와 복귀

상태: 이번 추가분 회귀 확인 완료.
종료 조건: 목록·상세·뒤로가기·직접 주소·새로고침·모음 복귀가 유지되고, 메모가 선택한 페이지와 위치에 연결됩니다.
기존 근거: 두 후보의 390px 핵심 이동과 빌드·타입 검사를 통과했습니다.
최종 결과: 두 후보의 390px 목록·상세·뒤로가기·직접 주소·새로고침·모음 복귀를 다시 통과했습니다. 홈 목록 클릭을 메모 위치 선택으로 가로채는 동작, 홈/자료실 메모 분리와 원래 위치 보존을 확인했습니다.

E3 · 체험 작성·댓글·내 활동

상태: 이번 추가분 체험 동선 확인 완료.
종료 조건: 체험 글·댓글·저장·내 활동·계정 분리·초기화가 유지되고, 디자인·메모 조작 때문에 작성 중인 내용이 사라지지 않습니다.
기존 근거: 두 후보의 합성 입력과 메모리 시연 동선을 통과했습니다. 실제 서버 권한 검증은 아닙니다.
최종 결과: 두 후보의 체험 로그인·글·댓글·글 저장·내 활동·계정 분리·새로고침 초기화를 통과했습니다. 시안을 불러와도 작성 중 본문을 유지했고, 내려받은 HTML에 그 입력과 다른 이름 저장본이 들어가지 않음을 합성 표식으로 확인했습니다.

E4 · 화면 크기·글자 확대·키보드

상태: 새 검토 화면 확인 완료.
종료 조건: 390·768·1280px와 글자 200%에서 검토 패널·메모·저장 조작이 가려지지 않고 키보드로 접근할 수 있습니다.
기존 근거: 대표 3화면 × 3폭 × 기본/200% 글자 크기 18조합에서 넘침·본문 건너뛰기·다음 포커스·오류를 확인했습니다. 루트 글자 크기 확대는 브라우저 전체 줌과 다릅니다.
최종 결과: 메모·저장·전달의 3패널 × 390/768/1280px × 글자 100%/200%, 총 18조합에서 가로 넘침이 없었습니다. 키보드 위치 선택과 Esc 취소, 내려받은 HTML의 오프라인 표시·메모를 확인했습니다. 기존 대표 화면 검증 범위와 합쳐도 모든 조합의 접근성 인증을 뜻하지 않습니다.

E5 · 디자인·위치 메모·이름 저장·에이전트 전달

상태: 복원·연결 및 로컬 검증 완료.
종료 조건: 32개 출발 조합·독립 7축·나란히 비교·취소·적용을 유지합니다. 위치 메모의 4색·편집·완료·삭제, 임시 저장, 원본을 보존하는 다른 이름 저장, 저장본 불러오기와 관리, JSON 별도 사본 가져오기가 동작합니다. JSON·Markdown·독립 시각 참고 HTML을 내려받아 같은 설정·메모·기준 원본을 확인할 수 있습니다. 기존 정적 편집기도 유지합니다.
기존 근거: 디자인 조합 단계의 홈 64개·설정 패널 3개·설정 흐름 1개, 총 68개 항목은 통과했습니다. 이번 추가분은 후보 29개(Claude 23개·Fable 6개)와 카탈로그·기존 편집기 21개, 총 50개 자동 검사를 통과했습니다.
최종 결과: 메모 추가·수정·완료·삭제·새로고침, 원본 보존 Save As·두 저장본 재열기, 저장본 삭제 시 작업 사본 보존, JSON 별도 사본 복원과 손상 파일 거부, JSON/Markdown/HTML 다운로드를 통과했습니다. A 적용 → B 임시 변경 → 즉시 새로고침 → 취소 때 A와 메모가 복원됩니다. 두 탭의 오래된 상태가 새 저장본을 덮지 않도록 충돌 시 자동 저장을 멈추고 JSON 보관·최신본 열기를 제공합니다. 독립 검토자가 두 탭에서 원본 보존·충돌 JSON 내보내기·최신본 이후 Save As를 확인했습니다.
확인 범위: 32개는 공통 축의 출발 조합입니다. 가능한 14,580개 전체 조합을 전수 검증한 것으로 취급하지 않습니다. 구 정적 편집기의 저장 데이터를 자동 이전한 것도 아닙니다.

E6 · 출처·라이선스·공개 범위

상태: 이번 저장·전달 추가분 독립 검토 완료.
종료 조건: 원본과 Codex 변경 기여를 구분하고 코드·폰트·이미지 고지를 유지합니다. 공개 파일에서 개인 자료·대화·세션·인증 정보를 제외합니다. 가져온 메모를 실행 지시로 처리하지 않으며 형식·크기·위치·개수를 제한합니다.
최종 결과: 구현 담당과 별도의 기능 검토 및 제품·공개 범위 검토를 완료했습니다. 적용/임시 상태 혼동과 여러 탭의 저장본 손실 문제를 수정하고 재확인했습니다. HTML은 별도 합성 화면에서 생성하고 스크립트·이벤트 속성을 제거하며 메모를 문자로 삽입합니다. 악성 문구의 미실행, 체험 입력·다른 저장본 미포함, 고지 포함을 확인했습니다. 후보 출처·생성물 해시를 갱신하며 로컬 QA 파일·설치 의존성은 공개하지 않습니다.

E7 · 상태 인계와 정지

상태: 현재 범위 기록 완료, 최종 검증·공개 인계 전.
종료 조건: E1–E6의 이번 결과와 배포 버전을 기록하고 메모·이름 저장·전달까지 사용할 수 있는 화면을 인계하면 종료합니다. 새 조사나 모델 재평가를 자동으로 시작하지 않습니다.
최종 결과: 로컬 검증 진행, 공개 전. 배포 주소·소스 버전·완료 조건·남은 선택을 여기에 기록합니다.

사용자가 이어서 할 일

  • 32개 출발 조합과 독립 축에서 원하는 외관을 선택합니다.
  • 페이지 위치에 조정 메모를 남기고 시안 이름을 정합니다.
  • 원본을 보존하려면 다른 이름으로 저장하고, JSON·Markdown·시각 참고 HTML을 내려받아 에이전트에게 전달합니다.

최종 외관 취향과 실제 인증·DB·운영·수익화는 이번 범위 밖입니다. 메모와 이름 저장을 React의 후속 기능으로 미루지 않고 이번 기능판에 연결합니다.
