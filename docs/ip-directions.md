‘제도와 일상’과 ‘일상동료’는 비교용 제안 이름이다. 최종 상호·상표·도메인은 결정하지 않았다. 상단에서 안을 이동하거나 세 기본 홈을 같은 폭으로 비교할 수 있다.

## 이번에 담은 정체성

사용자가 ‘보훈·군경 전직에 집중한 전문 커뮤니티’를 핵심 정체성으로 확정했다. 2·3안의 도입 문구뿐 아니라 분야 순서, 글 목록·작성 화면의 분야명, 예시 글, 읽을거리, 자료실과 소개에 함께 반영한다. 1안은 이전의 일반 커뮤니티 기준으로 보존한다.

- ‘보훈 안내 읽기’: 보훈 공식 안내의 기관·대상·시점·질문을 구분해 읽는다.
- ‘군·경 경력 정리’: 군 복무·경찰 근무의 경험을 다음 직무의 언어로 정리한다.
- ‘전역·퇴직 준비 노트’: 전역·퇴직 준비에서 먼저 확인할 질문을 정리한다.

세 편은 직접 작성한 편집 예시이고, 게시판의 12개 글도 군·경과 가족을 주제로 한 합성 질문이다. 실제 상담 사례·처리 실적·회원 경험·기관 제휴를 주장하지 않는다. 비공개 사건, 진단서, 내부 업무 기록을 사용하지 않았다. 보훈 대상 여부나 금액·기간 등 개인에게 적용되는 법률 판단을 제공하지 않는다.

군 전역자와 경찰 퇴직자의 지원 경로를 구분한다. 보훈부·제대군인지원센터·국방전직교육원·경찰청의 공식 안내를 연결하며, 경찰청 링크는 퇴직자 취업지원 담당 부서 안내이고 신청 페이지가 아니다. 2026-10-13 기관명·업무와 링크 응답을 확인했다.

- [국가보훈부](https://www.mpva.go.kr/mpva/index.do): 보훈 제도·지원 안내.
- [제대군인지원센터](https://www.vnet.go.kr/): 제대군인 취업·교육 지원.
- [국방전직교육원](https://www.moti.or.kr/): 군 전역 준비·전직교육.
- [경찰청 담당 부서](https://www.police.go.kr/www/agency/orginfo/orginfo0201.jsp): 복지정책담당관 복지지원계의 퇴직자 취업지원 업무. 현재 전직 프로그램을 한곳에 모은 전용 페이지는 확인하지 못했다.

## 기존 기능과 저장

32개 출발 조합과 화면·색상·목록·글꼴·여백·모서리·기호의 독립 7축을 세 안 모두에서 유지한다. 2·3안은 색만 바꾼 프리셋이 아니라 홈의 구성과 읽기 순서가 다른 안이다. 세 안 비교는 기본 디자인으로, 각 안 안의 디자인 비교는 현재 조합과 변경 조합으로 동작한다.

위치 메모·다른 이름 저장·저장본 관리·JSON 복원·Markdown 수정 요청·시각 참고 HTML도 유지한다. 각 안의 설정과 메모는 별도 브라우저 키에 보관한다. 다른 안의 JSON을 잘못 가져오면 해당 안으로 이동하도록 안내하며, 같은 안에서 가져올 때는 기존 저장본을 덮지 않는 사본으로 연다. JSON·Markdown·HTML에는 안 번호·이름·경로가 포함된다. 에이전트에게 자동 전송하지 않는다.

현재 안을 다시 눌러도 작성 화면을 새로 불러오지 않는다. 다른 안으로 이동할 때 미등록 글·댓글이 있으면 확인한다. 작성한 체험 글·댓글은 기존처럼 메모리 시연이며 실제 인증·DB와 연결되지 않는다.

기존 A/B/C 정적 편집기와 Fable 후보도 보존한다. A/B/C 편집기의 메모는 별도 형식이며 자동 이전하지 않는다.
